# CheckEM: VLM ensemble-based web content analysis

[CheckEM](https://www.checkem.tech/) analyses web pages for suspicious content using an ensemble of VLMs including closed frontier models through APIs and smaller open models. 

The application is focused on making it clear what parts of any web content raise suspicions and why. The ensemble of VLMs plays a key role by enabling the models to vote on both the full content of the page and any smaller sections which are flagged by any of the models. These give the user a clear output to follow and judge for themselves wether the AI judgement is reliable or not.
